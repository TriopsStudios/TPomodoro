# Pomodoro Timer Practice

This is a Pomodoro timer I created to test my GUI library: TUIL (Triops Usuary Interface Library).

The library is entirely written in C++ and uses SDL2 to facilitate image loading and rendering, as well as window management and instantiation.

Currently, it has only been tested on Windows, but since SDL2 is cross-platform, I plan to extend it to Linux soon.

## How to Run

Simply place the executable in a folder along with the "Fonts", "Images", and "SDL2" folders. You may need to extract the `.lib` files from the "SDL2/lib/x64" folder.

Alternatively, you can run it by compiling the code, as long as the paths are the same as those specified in the previous section.
